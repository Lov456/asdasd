# Программа складского учёта компьютерной техники

Веб-приложение и REST API для автоматизации складского учёта компьютерного оборудования, оргтехники и контроля их перемещения между складами и подразделениями организации. Проект разработан в рамках изучения МДК 04.01.

## Стек технологий
* **Язык программирования:** Python 3.14
* **Веб-фреймворк:** Django 6.1, Django REST Framework (DRF)
* **Документация API:** drf-spectacular (OpenAPI / Swagger)
* **База данных:** PostgreSQL / SQLite
* **Инструменты:** Git, VS Code

## Структура проекта
* `apps/accounts/` — управление учётными записями сотрудников и правами доступа.
* `apps/catalog/` — справочник складов (помещений) и каталог компьютерной техники с инвентарными номерами и статусами.
* `apps/clients/` — справочник отделов-получателей и материально ответственных лиц.
* `apps/orders/` — оформление складских операций (приёмка, выдача в эксплуатацию, списание, возврат).
* `apps/reports/` — формирование аналитических отчётов по остаткам и движению техники.
* `config/` — конфигурация проекта, маршрутизация URL и настройки базы данных.
